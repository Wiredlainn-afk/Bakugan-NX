Make the SD card package (version 0.2.0) of the Bakugan: Battle Brawlers port from your own copy of the Xbox 360 game. Everything runs in this browser tab: your game files never leave your computer.

Upgrading from 0.1.x? Delete the old shader and cache files first. Version 0.2.0 draws with a different renderer and does not read the old files; leftovers can make it start with a black screen or stutter. On the SD card, in sdmc:/switch/bakugan-nx/, delete:
    Keep game_root/. A new cache/deko3d_shaders.bin and cache/pipeline_list.bin are in the zip. The game adds new shader variants to deko3d_shaders.bin while you play (the first time in a place it can stutter for a moment), so extracting the zip over a cache you have already played with replaces it: it is built again as you play.

    3 Languages to include (optional)

    The game has voices and an intro movie in seven languages (each about 80 MB). Untick the ones you don't need to make the package smaller. If the game asks for a language you left out, it plays another installed language instead; the menus and text follow the language you choose in the game and are not affected. At least one must stay ticked.

    4 Create the package

    First install: the full zip, with the game files (about 3 GB). Update (a new release): only the program and its cache files, to extract over the existing folder (after deleting the old files listed above). Your game files are not touched.

      After it finishes
      
    
      Extract the zip into sdmc:/switch/ on the SD card. You get:
      

      /switch/bakugan-nx/
  bakugan.nro                   (the game's shaders are inside)
  cache/deko3d_shaders.bin      (compiled shader variants; the game adds the ones it has not seen)
  cache/pipeline_list.bin       (pipelines to prepare at the start)
  game_root/                    (the files of your disc)
      
    
      Launch it with a title override (hold R while starting an installed game) or a forwarder, with a
      39-bit address space. Album applet mode does not provide enough memory.
      bakugan.toml is optional (the settings are compiled in).
      
  
      

  
      
    
      Privacy
      
    
      
      The page reads your disc with your browser's own file access and writes the zip to your disk. The only network traffic is
      loading this page and downloading the build (bakugan.nro and the two cache files) from this site. No game data is uploaded, and there is no tracking.
      The game's files are not part of the port.
