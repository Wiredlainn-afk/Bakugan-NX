Make the SD card package of the Bakugan: Battle Brawlers port from your own copy of the Xbox 360 game. Everything runs in this browser tab: your game files never leave your computer.

1 Choose your game

The disc image of the Xbox 360 game.

or drop it here

2 Detected game

3 Languages to include (optional)

The game has voices and an intro movie in seven languages (each about 80 MB). Untick the ones you don't need to make the package smaller. If the game asks for a language you left out, it plays another installed language instead; the menus and text follow the language you choose in the game and are not affected. At least one must stay ticked.

4 Create the package

First install: the full zip, with the game files (about 3 GB). Update (a new release): only the program and the shaders, to extract over the existing folder. It needs the same game selected, because the shaders are made from it.

    After it finishes
    
    
    Extract the zip into sdmc:/switch/ on the SD card. You get:
    

    /switch/bakugan-nx/
  bakugan.nro
  bakugan_shaders.mesp          (the game's shaders, made from your disc)
  bakugan_shaders.mesp.idx      (index of the shader file)
  cache/                        (pipeline cache of the release, if published)
  game_root/                    (the files of your disc)
    
    
    Launch it with a title override (hold R while starting an installed game) or a forwarder, with a
      39-bit address space. Album applet mode does not provide enough memory. The settings file
      bakugan.toml is written next to the NRO at the first start.
    
  
    

  
    
    
    Privacy
    
    
    
      The page reads your disc with your browser's own file access, makes the shaders on your computer with WebAssembly and
      writes the zip to your disk. The only network traffic is loading this page and downloading the build
      (bakugan.nro and the pipeline cache) from this site. No game data is uploaded, and there is no tracking.
      The game's files are not part of the port.
